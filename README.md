## ✨ Features

- Hero banner with a welcome message and a "Register Now" call-to-action
- **Global News** section with cards for international, political, and education news
- **Sports** section covering general sports, cricket, and yoga
- **Entertainment** section covering celebrities, culture, and magazine content
- **Contact Us** section with location, email, phone, and a feedback form
- Separate **Registration Form** page with its own styling
- Social media links in the footer
- Hover effects on images and navigation links for a more interactive feel

## 🛠️ Built With

- **HTML5** – page structure and content
- **CSS3** – styling, layout (Flexbox & Grid), and hover animations

## 📁 Project Structure

```
├── index.html            # Homepage (news, sports, entertainment, contact)

├── style.css             # Styles for the homepage

└── images/                # Logo and section images
```
